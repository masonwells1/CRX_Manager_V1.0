## 2026-09-14 - Guards read `\ ` the way PowerShell does as well as the way POSIX does

- **What changed:** the shared command splitter (`splitCommandSegments` in `.claude/hooks/codex-push-lib.mjs`) now adds a third reading of a command, PowerShell's. In that reading a backslash before a space is an ordinary character and the space still starts a new word. The guards deny if any reading is refused.
- **Why:** the word splitter follows POSIX, where `\ ` joins two words. PowerShell keeps the backslash and splits. So `gh pr merge 123 --body x\ --admin --squash` was read as a merge without `--admin`, and `gh api -H X-Test:value\ -X DELETE repos/o/r/branches/main/protection` as a harmless GET. The Codex guard allowed the second one, which main denies. Found by the local gpt-5.6-sol review of PR #630 on 2026-09-14.
- **Proof:** both commands ran through the real guards as hook subprocesses. Before the fix the Codex guard allowed the DELETE; after it, the DELETE is denied, and the `--admin` merge is denied on a green PR. New shared-library and Codex end-to-end tests fail when the new reading is removed. A command with no backslash gains no extra reading, and the full correction-guard suite still passes.
